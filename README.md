# WhatsApp UI Clone (Dark Mode) - Flutter

Welcome to my very first Flutter application — a clean and responsive **WhatsApp chat UI clone**, recreated from scratch using **Figma** as a visual reference!

This project replicates the familiar dark mode chat screen of WhatsApp, focusing on pixel-perfect design, UX hierarchy, and responsiveness. It's built entirely with **Flutter**, showcasing custom widgets, styling, and layout techniques.

---

## Features

- **Dark Theme WhatsApp Chat UI**
- Custom-designed **AppBar** with user profile, status, and action icons
- Realistic **message bubbles** with clean alignment and colors
- Functional and stylish **input bar** with mic button and hint text
- Designed using Figma before implementation for accuracy and structure
- Color palette matches WhatsApp:
  - Green: `#168C4B`
  - Black: `#181818`
  - White: `#FFFFFF`

---

## Tech Stack

- **Flutter** (Frontend UI Framework)
- **Figma** (Design and UI planning)
- Dart programming for layout and widget logic
